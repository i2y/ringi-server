# 受け付けない理由

操作が決まりに合わないとき、サーバーは何も変えず、理由を返します。ページには、理由の文が出ます。API の応答（409）では、`refused` に理由の種類が入ります。種類は次の 12 個です。英語版は [refusals.md](refusals.md) です。

ページでは、文の下の「申請を管理している人向けの詳細」を開くと、どの決まりのどこに合わなかったかを読めます。帳簿の理由（`book`）は、そこに畳まずに、文のすぐ下に出します。使う人に向けて書かれた文だからです。

| `refused` | ページに出る文 | 起きるとき |
|---|---|---|
| `state` | この申請は、今の状態ではこの操作を受け付けません。 | 終わった申請を操作した。戻ってきた申請を承認した。取り下げられる時期を過ぎた |
| `clock` | この申請の期限の処理が、まだ終わっていません。少し待ってから、もう一度送ってください。 | 期限の時刻が来て、サーバーがそれを処理する前に操作した |
| `stale` | このページを開いたあとで、申請が変わりました。今の申請を表示しています。確かめてから、もう一度送ってください。 | 開いたあとで、ほかの人が承認した、承認者が入力した、など |
| `person` | この操作はできません。 | 承認者でも代理でもない。もう答えた。自分の申請を承認しようとした。gate が許していない |
| `event` | この申請の種類には、この操作がありません。 | 申請の種類に書いていない操作をした。差し戻せないステップに差し戻した。同じ承認者を二度加えた |
| `limit` | この操作の回数か日数の上限に達しています。 | 差し戻し、取り下げ、保留の回数か日数を使い切った |
| `form` | 受け付けられない値があります。印の付いた項目を確かめてください。 | 範囲の外の値、空の必須の項目、選択肢にない値。次のステップの承認者を選んでいない |
| `comment` | コメントを受け付けられませんでした。コメントを確かめてください。 | コメントが要る操作で空にした。2,000 字を超えた |
| `submit` | この申請を出せる人に入っていません。 | 申請の種類の `submitted by` に入らない人が申請した |
| `data` | 会社が用意したデータでは、この日付の申請を扱えません。この申請を管理している人に問い合わせてください。 | その日に有効な組織のデータがない。申請の種類が使える期間の外の日。カレンダーで期限を数えられない |
| `book` | 帳簿（予算や休暇の日数など）が、この操作を受け付けませんでした。 | 予算や休暇の残りが足りない。どの部の帳簿に付けるかが決まらない |
| `unread` | この申請を処理できませんでした。この申請を管理している人に問い合わせてください。 | 版を上げずに申請の種類を変えたため、進行中の申請が読めない |

`form` の応答には、フォームのどの項目かが `at` に入ります。明細の行の中なら `items[1].price` のように、行を 0 から数えます。ページでは、その項目に印が付きます。

`book` の応答の `text` と `text_ja` は、帳簿が返した理由です（「部の予算が足りません」など）。ページでは、ページの文のすぐ下に出ます。

## 管理する人の操作

| `refused` | 起きるとき |
|---|---|
| `stale` | ほかの管理者が先に切り替えた。確かめたあとで、別のデータが取り込まれた |
| `owner` | 申請の種類をほかのチームに移す切り替えで、移す先のチームを管理できない |
| `locks_out` | 取り込むと、自分が取り込めなくなるデータだった。わかったうえで取り込むなら、`locks_out: true` を付ける |

## 理由の付かない応答

| ステータス | ページに出る文 | 起きるとき |
|---|---|---|
| 401 | ログインしていません | ログインしていない。セッションが終わった |
| 403 | 送った内容を読めませんでした | ほかのサイトのページから送られた |
| 404 | 見つかりません | その番号の申請がない。または、その人は見られない |
| 413 | 送った内容が大きすぎます | 添付ファイルか本文が、上限を超えている |
| 429 | 待つ秒数、または、もうコメントを付けられないこと | 続けてコメントした。コメントの数の上限に達した |
| 500 | サーバーのエラー | サーバーの失敗。理由はログにある（[監視する](troubleshooting.ja.md#ログを見る)） |
